# Inviteus

معرض دعوات إلكترونية. صفحة الزوار هي `index.html`، ولوحة إدارة الدعوات هي `admin.html`.

## نشر الموقع

من إعدادات مستودع `novixai29/Inviteus-` فعّل GitHub Pages واختر النشر من فرع `main` ومجلد الجذر `/`. بعد النشر يصبح رابط المعرض:

`https://novixai29.github.io/Inviteus-/`

ورابط لوحة الإدارة:

`https://novixai29.github.io/Inviteus-/admin.html`

## دخول اللوحة

أنشئ رمز وصول **Fine-grained personal access token** من إعدادات GitHub، وحدد مستودع `Inviteus-` وحده، ومنحه صلاحية **Contents: Read and write**. أدخل الرمز في لوحة الإدارة. لا تضعه في ملفات المستودع أو ترسله لأحد. اللوحة لا تحفظه في تخزين المتصفح، ويجب إدخاله من جديد عند إعادة فتح الصفحة.

رابط لوحة الإدارة مرئي لأي شخص يعرفه، لكن إضافة الدعوات أو تعديلها أو حذفها يتطلب رمز GitHub المصرح له. احذف الرمز من إعدادات GitHub متى أردت إيقاف الوصول.

## إدارة الدعوات

أدخل اسم الدعوة، المناسبة، الوصف، رابط مستودعها، ورابط النسخة المنشورة. يظهر الموقع النسخة المنشورة مباشرة على مساحة عرض البطاقة كاملة؛ لا تحتاج إلى صورة عرض. إن كان لديك رابط منفصل لصفحة عرض داخل الدعوة، ضعه في حقل «رابط العرض داخل البطاقة»، وإلا اتركه فارغاً. اختر الأسلوب والتفاصيل الموجودة فعلاً داخل الدعوة. عند الحفظ أو الحذف، تحدّث اللوحة ملف `catalog.json` في المستودع. يقرأ معرض الزوار هذا الملف عبر GitHub API عند فتح الصفحة وعند العودة إليها، ويتحقق دورياً أثناء بقائها مفتوحة. قد يتأخر ظهور التغيير قليلاً بسبب ذاكرة GitHub المؤقتة أو حد طلبات API. إذا تعذر الاتصال، يعرض الموقع نسخة الدعوات الأصلية المضمّنة فيه.

تُضاف الدعوة الجديدة في نهاية `catalog.json`، ويعرضها الموقع واللوحة أولاً. تظهر ٨ دعوات في كل صفحة، مع أزرار الصفحات أعلى القائمة وأسفلها. تتحرك معاينة الدعوات المضمّنة داخل الموقع عند مرور المؤشر، ويمكن سحبها أفقياً على الموبايل لمشاهدة أجزاء مختلفة؛ ويبقى رابط «جرّب الدعوة» هو التجربة الكاملة. للدعوات المستضافة في موقع آخر يمكن للزائر تصفح الإطار يدوياً. وإذا أردت حركة تلقائية مضمونة، ضع رابط فيديو معاينة صامت مباشر بصيغة MP4 أو WebM في الحقل الاختياري؛ تبقى الدعوة المنشورة نفسها هي الرابط الذي يفتحه الزائر عند اختيارها.

صور العرض القديمة في مجلد `previews` لم تعد تُستخدم في واجهة المعرض. الدعوات الجديدة لا ترفع صوراً. عند حذف بطاقة قديمة، تحاول اللوحة تنظيف صورتها المرفوعة إذا كانت تخص تلك البطاقة وحدها.

رابط GitHub نفسه لا يفتح كتجربة دعوة؛ استخدم رابط النسخة المنشورة في حقل «رابط الدعوة المنشورة». اللوحة تقترح رابط GitHub Pages تلقائياً عندما تدخل رابط المستودع، فتأكد أن الدعوة منشورة فعلاً على ذلك الرابط.

معاينة البطاقة تحمل الصفحات عند اقترابها من الشاشة حتى يبقى التصفح أخف على الموبايل. إذا كانت الدعوة تمنع عرضها داخل إطار، يبقى زر «جرّب الدعوة» يفتحها كاملة في صفحة مستقلة؛ استخدم رابط صفحة عرض تسمح بالإطار لو أردت ظهورها داخل البطاقة.
