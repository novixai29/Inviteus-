# Inviteus

معرض دعوات إلكترونية. صفحة الزوار هي `index.html`، ولوحة إدارة الدعوات هي `admin.html`.

## نشر الموقع

من إعدادات مستودع `novixai29/Inviteus-` فعّل GitHub Pages واختر النشر من فرع `main` ومجلد الجذر `/`. بعد النشر يصبح رابط المعرض:

`https://novixai29.github.io/Inviteus-/`

ورابط لوحة الإدارة:

`https://novixai29.github.io/Inviteus-/admin.html`

## دخول اللوحة

أنشئ رمز وصول **Fine-grained personal access token** من إعدادات GitHub، وحدد مستودع `Inviteus-` وحده، ومنحه صلاحية **Contents: Read and write**. أدخل الرمز في لوحة الإدارة. لا تضعه في ملفات المستودع أو ترسله لأحد. اللوحة لا تحفظه في تخزين المتصفح، ويجب إدخاله من جديد عند إعادة فتح الصفحة.

رابط لوحة الإدارة مرئي لأي شخص يعرفه، لكن إضافة الدعوات أو تعديلها أو حذفها يتطلب رمز GitHub المصرح له. احذف الرمز من إعدادات GitHub متى أردت إيقاف الوصول.

## إدارة الدعوات

أدخل اسم الدعوة، المناسبة، الوصف، رابط مستودعها، رابط النسخة المنشورة، وصورة عرض مقتطعة من أجمل جزء منها. اختر الأسلوب والتفاصيل الموجودة فعلاً داخل الدعوة. عند الحفظ أو الحذف، تحدّث اللوحة ملف `catalog.json` في المستودع. يقرأ معرض الزوار هذا الملف عبر GitHub API عند فتح الصفحة وعند العودة إليها، ويتحقق دورياً أثناء بقائها مفتوحة. قد يتأخر ظهور التغيير قليلاً بسبب ذاكرة GitHub المؤقتة أو حد طلبات API. إذا تعذر الاتصال، يعرض الموقع نسخة الدعوات الأصلية المضمّنة فيه.

صورة العرض المرفوعة تُحفظ في مجلد `previews`. عند حذف البطاقة، تحاول اللوحة حذف صورتها المرفوعة أيضاً إذا لم تستخدمها بطاقة أخرى. وكذلك تنظّف الصورة القديمة عند استبدالها بصورة جديدة.

رابط GitHub نفسه لا يفتح كتجربة دعوة؛ استخدم رابط النسخة المنشورة في حقل «رابط الدعوة المنشورة». اللوحة تقترح رابط GitHub Pages تلقائياً عندما تدخل رابط المستودع، فتأكد أن الدعوة منشورة فعلاً على ذلك الرابط.
