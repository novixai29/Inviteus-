# Inviteus

معرض للتصاميم الرقمية: دعوات الخطوبة والحنة والزفاف والمؤتمرات والافتتاحيات، والمتاجر، وقوائم الطعام، وقوائم المشروبات. صفحة الزوار هي `index.html`، ولوحة إدارة التصاميم هي `admin.html`.

## نشر الموقع

من إعدادات مستودع `novixai29/Inviteus-` فعّل GitHub Pages واختر النشر من فرع `main` ومجلد الجذر `/`. بعد النشر يصبح رابط المعرض:

`https://novixai29.github.io/Inviteus-/`

ورابط لوحة الإدارة:

`https://novixai29.github.io/Inviteus-/admin.html`

## دخول اللوحة

أنشئ رمز وصول **Fine-grained personal access token** من إعدادات GitHub، وحدد مستودع `Inviteus-` وحده، ومنحه صلاحية **Contents: Read and write**. أدخل الرمز في لوحة الإدارة. لا تضعه في ملفات المستودع أو ترسله لأحد. تحفظه اللوحة مؤقتاً في جلسة تبويب المتصفح حتى تتجاوز إعادة التحميل على الموبايل؛ يمسحه زر «خروج». لا يُرسل الرمز إلى أي جهة غير GitHub API.

رابط لوحة الإدارة مرئي لأي شخص يعرفه، لكن إضافة التصاميم أو تعديلها أو حذفها يتطلب رمز GitHub المصرح له. احذف الرمز من إعدادات GitHub متى أردت إيقاف الوصول.

## إدارة التصاميم

أدخل اسم التصميم، القسم، الوصف، ورابط النسخة المنشورة. يقسم الموقع التصاميم إلى «تصميم الدعوات» وفيه خطوبة، حنة، زفاف، مؤتمرات، وافتتاحيات، و«التجارة الإلكترونية» وفيه متاجر، قوائم الطعام، وقوائم المشروبات. يظهر الموقع النسخة المنشورة مباشرة على مساحة عرض البطاقة كاملة؛ لا تحتاج إلى صورة عرض. إن كان لديك رابط منفصل لصفحة عرض داخل التصميم، ضعه في حقل «رابط العرض داخل البطاقة»، وإلا اتركه فارغاً. اختر الأسلوب والتفاصيل الموجودة فعلاً داخل التصميم. عند الحفظ أو الحذف، تحدّث اللوحة ملف `catalog.json` في المستودع. يعيد الموقع قراءة الملف من GitHub عند الفتح والعودة إلى الصفحة؛ وإذا تعذّر الاتصال بـ GitHub API يجرب نسخة الموقع المنشورة. قد يتأخر ظهور التغيير قليلاً بسبب نشر GitHub Pages أو ذاكرة التخزين المؤقت.

اللوحة تحفظ مسودة التصميم في جلسة تبويب المتصفح أثناء الكتابة. عند إعادة تحميل الصفحة تعيد جلسة الدخول والمسودة، وتظهر رسالة الحفظ أو الخطأ أسفل الشاشة. بعد الحفظ الناجح تنتقل إلى بداية قائمة التصاميم لرؤية البطاقة الجديدة. إذا انتهت صلاحية رمز GitHub، أدخله من جديد؛ تبقى مسودة التصميم محفوظة في هذا التبويب حتى ينجح الحفظ أو تختار «خروج».

يُضاف التصميم الجديد في نهاية `catalog.json`، ويعرضه الموقع واللوحة أولاً. تظهر ٨ تصاميم في كل صفحة، مع أزرار الصفحات أعلى القائمة وأسفلها. تتحرك معاينة التصاميم المضمّنة داخل الموقع عند مرور المؤشر، ويمكن سحبها أفقياً على الموبايل لمشاهدة أجزاء مختلفة؛ ويبقى رابط تجربة التصميم هو التجربة الكاملة. للتصاميم المستضافة في موقع آخر يمكن للزائر تصفح الإطار يدوياً. وإذا أردت حركة تلقائية مضمونة، ضع رابط فيديو معاينة صامت مباشر بصيغة MP4 أو WebM في الحقل الاختياري؛ تبقى النسخة المنشورة نفسها هي الرابط الذي يفتحه الزائر عند اختيارها.

صور العرض القديمة في مجلد `previews` لم تعد تُستخدم في واجهة المعرض. التصاميم الجديدة لا ترفع صوراً. عند حذف بطاقة قديمة، تحاول اللوحة تنظيف صورتها المرفوعة إذا كانت تخص تلك البطاقة وحدها.

اللوحة لا تطلب رابط مستودع أي تصميم ولا تحفظه؛ المطلوب هو «رابط التصميم المنشور» الذي يفتحه الزائر. تُحذف حقول `repoUrl` القديمة من بيانات المعرض عند الحفظ التالي. يبقى مستودع Inviteus نفسه وسيلة لحفظ قائمة التصاميم وإدارتها. إزالة رابط مستودع التصميم لا تغيّر خصوصيته على GitHub ولا تحذف الروابط من سجل التعديلات السابق؛ المستودع العام يظل عاماً، وملفات الواجهة التي يرسلها أي موقع منشور إلى المتصفح تظل قابلة للعرض.

معاينة البطاقة تحمل الصفحات عند اقترابها من الشاشة حتى يبقى التصفح أخف على الموبايل. إذا كان التصميم يمنع عرضه داخل إطار، يبقى زر تجربة التصميم يفتحه كاملاً في صفحة مستقلة؛ استخدم رابط صفحة عرض تسمح بالإطار لو أردت ظهوره داخل البطاقة.
