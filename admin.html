إدارة التصاميم

أضف دعوة، متجراً، أو قائمة طعام ومشروبات، وحدّد القسم ورابط التصميم المنشور. تقدر تعدّل أو تحذف أي تصميم؛ الأحدث يظهر أولاً، وكل صفحة تضم ٨ تصاميم. معاينة البطاقة تتحرك عند التأشير، ويمكن لمسها أو سحبها بالموبايل.

دخول المالك

أدخل رمز وصول GitHub المخصص لمستودع Inviteus. يبقى الرمز في جلسة هذا التبويب حتى لا تضيع إضافتك إذا أعاد الموبايل تحميل الصفحة، ويُمسح عند الخروج.
